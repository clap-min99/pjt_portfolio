### 실행 방법

#### 1. 필요한 파일

    아래 파일이 같은 폴더에 있어야 합니다

    RPS_yolo/
    ├── RPS_game.py     ← 메인 게임 스크립트
    ├── trt_module.py          ← TensorRT 추론 엔진 래퍼
    └── RPS_YOLO.engine        ← trtexec로 변환한 엔진 파일 (젯슨에서 생성)

#### 2. 실행

**카메라(웹캠) 연결, X_launch 실행**시킨 상태에서 RPS_game_YOLO.py 파일이 있는 폴더로 이동 후

`python RPS_game_YOLO.py` 입력

카메라 화면이 뜨면 준비 완료. 

화면 상단에 P1/P2 점수, 하단에 상태 메시지가 표시됨.

#### 3. 플레이 방법

카메라 앞에 두 명이 양손을 동시에 보여줌 (왼쪽 사람 = P1, 오른쪽 사람 = P2)

가위/바위/보 중 하나로 손 모양을 유지

일정 시간 안정적으로 유지되면 자동으로 판정

결과가 화면에 2초간 표시되고, 승리 시 점수 자동 반영

자동으로 다시 대기 상태로 돌아감

#### 4. 키 조작
키	동작
r	P1 / P2 누적 점수 초기화
q	게임 종료
