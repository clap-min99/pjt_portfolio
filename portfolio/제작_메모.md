## 내용 기준

이름·연락처·교육 및 프로젝트 개요는 저장소 README를 기준으로 작성했습니다. 경북대학교 전자재료공학과, ADsP, 품질경영기사, OPIc IH, JPT 420점은 사용자 제공 정보입니다. 사용자 요청에 따라 프로필의 협업 항목은 제외했습니다. 학위 취득 여부·졸업 연월·자격 및 어학 취득일은 제공되지 않아 기재하지 않았습니다.

BoardGuard 개인 기여는 사용자 확인을 바탕으로 모델 선정·학습, 데이터 촬영·정리·전처리, Jetson 신호 오류 해결, 팀장으로 한정했습니다. 다른 시스템 기능은 팀 구현으로 구분했습니다. 트러블슈팅의 저항 위치는 문서에 기록된 '신호선 구간에 10kΩ 추가' 이상으로 추정하지 않았습니다.

BoardGuard 최종 모델과 평가 수치는 BoardGuard/README.md를 따랐습니다. 체크인된 초기 학습 노트북에는 resnet18, normal_split_ratio=0.2가 있고, README에는 최종 wide_resnet50_2 model_03이 기록되어 있습니다. 최종 모델의 학습·검증·테스트 분할과 원본 평가 로그를 완전히 확인할 수 없어, 최종 분할 비율을 추정하지 않았습니다. 데이터 수는 독립 테스트셋 수로 표현하지 않았으며 수치를 내부 평가 기록으로 표시했습니다.

RPS_YOLO의 수치는 README 기록이며 현재 장비에서 재측정하지 않았습니다. 2.1ms는 trtexec GPU latency로 전체 영상 처리 속도와 구분했습니다.

달디단은 공개 README의 역할 표와 사용자 확인에 따라 XGBoost 초기 실험과 프론트엔드 기여를 기술했습니다. 최종 CNN·MLP 모델 개발·성능은 개인 성과에 포함하지 않았습니다. 초기 실험의 데이터 수·정확도는 확인되지 않아 추가하지 않았습니다.

시연 이미지는 기존 GIF의 프레임을 추출했습니다. PDF에는 클릭 가능한 저장소·이메일 링크가 있습니다. 공개 링크의 향후 접근 가능성은 저장소 공개 상태에 따라 달라집니다.

## 생성·검수

프로젝트 로컬 `.portfolio-tools`에 reportlab 4.2.5와 pymupdf를 설치했습니다. 시스템 Python 환경은 변경하지 않았습니다. `python portfolio/build_portfolio.py`로 재생성합니다. 맑은 고딕 폰트를 PDF에 포함합니다.

10페이지·A4 세로형 크기·한글 텍스트 추출·링크 주석 존재를 검사하고 전 페이지를 이미지로 렌더링해 검토했습니다. 모델 학습·Jetson 추론·하드웨어 동작은 재실행하지 않았습니다.
