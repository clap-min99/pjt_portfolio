I2C 센서별 파형

XSim에서 기록한 SDA/SCL 전이입니다. CH1 = SCL, CH2 = SDA. 센서와 확대 배율을 선택하고, 바이트 버튼을 누르면 해당 구간으로 이동합니다.

바이트는 MSB부터 8비트, 9번째 클럭은 ACK(0) 또는 NACK(1)입니다. 첫 DATA 뒤 ACK와 마지막 DATA 뒤 NACK는 Master가 보냅니다. 표시 전압 0/3.3V는 논리 0/1을 환산한 눈금입니다. 실제 상승시간·노이즈·오버슈트는 모델링하지 않습니다. 이 테스트는 선택 센서의 2바이트 읽기이며, 보드 기본 동작인 8바이트 전체 읽기와 구분됩니다.
